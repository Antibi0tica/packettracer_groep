Je kan groepen aanmaken als docent zijnde.

Zodra je groepen hebt aangemaakt kan je zelf de code zien en zien dat de groep is aangemaakt. 

Als student zijnde kan je de groep joinen als je de code hebt. Daarna krijg je zelf op je overview te zien dat je in die groep zit.

De docent kan zelf ook zien hoevele mensen in de groep zitten
