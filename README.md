Hi, 
Wegens een school SCRUM project waar ik de opdracht kreeg om een vernieuwde versie te maken van het domein "Packettracer.nl". Het doel was om de website te vernieuwen met bijvoorbeeld een nieuwe inlog pagina of een groep maker. 

Mijn keuze was uiteindelijk een project over het maken van groepen. Hierbij had ik een map aangemaakt met functies wat ik uiteindelijk kon gebruiken in een ander bestand. 

Wat kan je hier nou mee? 
Je kan een groep aanmaken alleen als docent zijnde. Zodra je een groep aanmaakt word deze groep met informatie gestuurd naar een JSON bestand. Je krijgt in beeld ook een unieke code wat de studenten kunnen gebruiken om in de groep te komen. Zodra een student is ingelogd kan de student met een groep meedoen en de code invullen. Je zal uiteindelijk zien dat je in die groep zit en de docent ziet tevens hoeveel er ook in zitten. 

Er zijn meerdere checks om te kijken of de docent daadwerkelijk inlogd en niet dat een student een groep kan aanmaken. 

Hoe heb ik dit gedaan?

Ik heb dit met kennis vanuit PHP gedaan en uiteraard ook deels met ChatGPT (Hoewel ik niet veel hiervan heb overgenomen was het altijd handig om te weten wat sommige functies doen) En naarmate dat de code af was bleef ik ook herhalen wat de code daadwerkelijk doet.

Ik vind dat het project aan het doel voldoet en dat ik hiermee een goed resultaat heb opgeleverd. Naast dat was ik zelf ook van plan om een functie aan te maken om groepen te verwijderen maar ik had hiervoor geen tijd.
